# Body Mass (BMI) Calculator

A simple, responsive BMI calculator using metric units (kg, cm). Enter gender, weight, and height to compute BMI, view the category, and see the healthy weight range for your height.

## Run locally

Open `index.html` in any modern browser. No build step or dependencies required.

## Usage

1. Select gender (used for context text; BMI categories are the same for adults).
2. Enter weight in kilograms (e.g., 70).
3. Enter height in centimeters (e.g., 175).
4. Click "Calculate" to see:
   - BMI value
   - BMI category (WHO standard)
   - Healthy weight range for your height
5. Click "Reset" to clear the form and results.

## Notes

- BMI is a screening tool and may not reflect body fat or health for everyone (e.g., athletes, older adults, pregnancy).
- Categories are intended for adults (18+).

## Files

- `index.html`: Markup and app structure
- `style.css`: Styles and layout
- `app.js`: Logic for validation and BMI computation
